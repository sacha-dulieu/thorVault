How automatic discovery works
<<<<<<< HEAD

1. Add folders. Android does not let ThorVault search the entire device. Add each accessible ROM, emulator, or save folder that may contain battery saves.

2. Select locations to scan. Folder choices and scan checkboxes are remembered. Scan only selected locations or deselect large folders temporarily.

3. Watch progress. ThorVault reports entries checked and candidates found as it runs. You can cancel, and partial results are retained when you cancel or hit a safety limit.

4. Review candidates. ThorVault uses filename, path, system and emulator patterns, plus exact SHA-256 fingerprints to flag likely saves and duplicate contents. Detection is a hint; review each result before opening it.

=======

1. Grant a folder. Android does not let ThorVault search the entire device. You choose one accessible emulator, ROM, or saves folder.

2. ThorVault remembers it. Android retains the permission after app and device restarts.

3. ThorVault scans inside it. It searches subfolders for files named main or ending in .sav, .dsv, .dat, or .bin.

4. Open a result. The server identifies the actual Pokémon game; the filename alone is only a candidate.
